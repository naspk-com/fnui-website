# 统计数值 FnStatistic

突出展示单个统计数值及其单位。

## 使用说明

- `FnStatistic`：必填的 `label` 和字符串或有限数值 `value`，可选 `unit`。
  使用语义化描述列表；格式化和精度由调用方负责。
- 这些组件在两个平台上都是纯展示组件。无事件或暴露的 ref 方法；不提供编辑、
  虚拟化、自动排序、日期/数字本地化以及完整的 TDesign API。
